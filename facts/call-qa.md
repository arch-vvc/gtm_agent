# Fact sheet: voice agent call QA demo

Repo: https://github.com/arch-vvc/voice-agent-call-qa
Names: voice agent call QA, call QA

## What it does
- voice agent call QA takes a client's call script (SOP), runs about 20 simulated callers against a voice agent, including Hinglish and adversarial callers, has a judge score every call against the script, and shows the exact failing turns on a dashboard so one prompt fix can be tested and the pass rate compared.

## What it does not measure
- latency
- response time
- speech recognition accuracy
- voice quality
- call volume
- at scale
- telephony
- SIP
- compliance certification
- uptime

## Numbers you may quote
- 20 simulated callers
